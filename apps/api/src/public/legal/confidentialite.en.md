# Privacy Policy

_Last updated: to be set before production launch._

## 1. Data collected

The service collects the email address and username needed to create an
account, along with the information the user chooses to enter about the
people who matter to them (dates, notes, wishes).

## 2. Purpose of processing

This data is used solely to operate the service: sending reminders,
displaying the user's Wall, and enabling the exchanges the user explicitly
authorizes with the people close to them.

## 3. Retention

Data is retained for as long as the account stays active. Deleting an
account results in the erasure of personal data after a grace period,
unless a legal obligation requires otherwise.

## 4. Sharing with third parties

Data is neither sold nor shared for advertising purposes. A technical
processor may access it strictly to the extent necessary to operate the
service (hosting, sending notifications).

## 5. User rights

The user may request an export or deletion of their data at any time from
their account settings.

## 6. Security

The service stores no passwords: authentication relies on one-time codes.
Session tokens are stored in hashed form.
