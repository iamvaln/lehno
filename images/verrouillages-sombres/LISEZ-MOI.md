# Verrouillage horizontal — surfaces sombres

Cinq fichiers. La pastille porte **#9C8BD8**, le violet du thème sombre, et le
`h` de la pastille passe à l'encre **#15131D** : un blanc sur ce violet ne
mesure que 2,96:1. Le mot reste blanc, le `o` abricot.

| Fichier | Fond | Pour |
|---|---|---|
| `…-blanc.svg` | transparent | **Le code.** Se pose sur les quatre surfaces ci-dessous |
| `…-sombre-barre.svg` | `#131219` | Barre latérale, en-têtes |
| `…-sombre-page.svg` | `#17161F` | Fond de page |
| `…-sombre-carte.svg` | `#1B1928` | Carte posée sur la page |
| `…-sombre-lilas.svg` | `#2E2945` | Aplat de mise en avant |

**En code, prenez la version transparente.** Les quatre autres existent pour les
supports où le fond est figé — une image de partage, un export, une maquette
plate. Une plaque posée sur une surface qui n'est pas exactement la sienne
dessine un rectangle : c'est le défaut qu'on vient de corriger.

La marge des versions à plaque vaut 42 unités, la largeur de la hampe — la zone
de protection de la charte. La version transparente est recadrée au tracé
(519,75 × 168) : c'est la mise en page qui donne l'air.
