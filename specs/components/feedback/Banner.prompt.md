Bandeau de message — une icône, une phrase. C'est **une bande, pas une carte** : angles droits, aucune bordure, aucune ombre.

```jsx
<Banner intent="success">Message envoyé à Valery.</Banner>
<Banner intent="error">Ce lien n'est plus valable.</Banner>
```

L'abricot reste hors de ce jeu — il célèbre, il n'avertit pas ; l'avertissement prend l'ambre saturé. `onDismiss` seulement si le message survit au changement d'écran.
